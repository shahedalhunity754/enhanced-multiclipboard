## Usage Examples
| Command | Description |
| :--- | :--- |
| `py mcb.pyw save <keyword>` | Saves current clipboard content to the specified keyword |
| `py mcb.pyw <keyword>` | Loads content associated with the keyword into the clipboard |
| `py mcb.pyw list` | Copies all saved keywords to the clipboard |
| `py mcb.pyw delete <keyword>` | Deletes a specific keyword from storage |
| `py mcb.pyw delete` | Deletes all saved keywords |
